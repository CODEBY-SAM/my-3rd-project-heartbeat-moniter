❤️ Heartbeat Monitor with Alert System

# 📌 Project Description

 * Heartbeat Monitor with Alert System is an embedded systems project designed to monitor a person's heart rate in real time. The system uses a heartbeat/heart-rate sensor to detect the pulse and calculates the heart rate in BPM (Beats Per Minute).

The measured heart rate can be displayed on an LCD/OLED display. If the detected heart rate goes beyond the predefined safe range, the system activates an alert mechanism such as a buzzer or LED.

This project demonstrates the practical use of microcontrollers, sensors, real-time monitoring, signal processing, and alert systems in an embedded environment.

  #🎯 Objectives

- Monitor heart rate in real time.
- Calculate heart rate in BPM.
- Display the measured heart rate.
- Detect abnormal heart-rate conditions.
- Generate an alert when the predefined limit is exceeded.
- Understand sensor and microcontroller interfacing.

# ⚙️ Main Components

- Microcontroller – Arduino/ESP32
- Heartbeat/Heart Rate Sensor
- LCD/OLED Display
- Buzzer
- LED
- Jumper Wires
- Breadboard
- Power Supply

# 🔄 Working Principle

1. The heartbeat sensor detects the pulse signal.
2. The microcontroller reads the sensor output.
3. The pulse data is processed to calculate BPM.
4. The current heart rate is displayed on the screen.
5. The system compares the BPM with predefined limits.
6. If an abnormal value is detected, the buzzer/LED provides an alert.
